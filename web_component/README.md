# web_component

vue-cli project that builds `components/ShogiPlayer.vue` into the `<shogi-player-wc>` Web Component and the UMD library in `../dist/`.

Build from the repository root with `npm run build` (see the [development guide](../main_doc/docs/guide/development.md)).

For local experiments inside this folder:

| Command  | What it does                           |
|----------|----------------------------------------|
| `rake s` | Serve the Vue version at port 4005     |
| `rake w` | Build the Web Component into `labo/` and open it |
